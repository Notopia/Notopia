## Features

| Feature | Description |
| --- | --- |
| **Intervals** | Choose an interval type (unison, second, third...) and see it rendered on the staff. |
| **Scales** | Pick a root note and a scale type (Major, Natural Minor, Chromatic and more) to display the full scale. |
| **Piano** | A virtual piano with real note sounds, playable right in the browser. |
| **Quizzes** | Test yourself on intervals and scales at easy and hard levels, then review your results in a chart. |
